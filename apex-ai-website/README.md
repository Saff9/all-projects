# 🚀 Apex AI | Next-Gen Intelligence

A premium, high-performance AI platform landing page built with **Next.js 15**, **Tailwind CSS 4**, and **Framer Motion 12**.

---

## ⚡ Quick Start

1. **Install Dependencies**:
   ```bash
   npm install
   ```
2. **Run Development Server**:
   ```bash
   npm run dev
   ```
3. **Build for Production**:
   ```bash
   npm run build
   ```

---

## ☁️ Vercel Deployment Guide

This project is fully optimized for **Vercel** with Next.js 15 and Tailwind 4.

### 1. One-Click Deploy
[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fvercel%2Fnext.js%2Ftree%2Fcanary%2Fexamples%2Fhello-world)

### 2. Manual Deployment Steps
1. **GitHub Integration**: Push your code to a GitHub/GitLab/Bitbucket repository.
2. **New Project**: In the [Vercel Dashboard](https://vercel.com/new), click **"Add New"** > **"Project"**.
3. **Import**: Select your repository.
4. **Framework Preset**: Vercel will automatically detect **Next.js**.
5. **Install Command**: Ensure it uses `npm install` or `bun install`.
6. **Environment Variables**: Add any necessary keys (e.g., `NEXT_PUBLIC_API_URL`) in the "Environment Variables" section.
7. **Deploy**: Hit **"Deploy"**. Your site will be live in seconds.

### 3. Vercel Configuration
The project includes a `next.config.ts` optimized for Vercel, including:
- ✨ **Image Optimization**: Ready for remote patterns.
- ⚡ **Performance**: React Strict Mode and compression enabled.
- 🛡️ **Security**: Powered-by headers disabled.

## 🛠️ Tech Stack
- **Framework**: [Next.js 15 (App Router)](https://nextjs.org)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com) (Lightning fast CSS-first engine)
- **PostCSS**: `@tailwindcss/postcss` integration
- **Animations**: [Framer Motion 12](https://framer.com/motion)
- **Theming**: `next-themes` (Atmospheric Dark/Light mode)
- **Icons**: [Lucide React](https://lucide.dev)

---

## 📦 Architecture
- `src/app`: App Router, Layouts, and Global Styles.
- `src/components/sections`: Modular, reusable landing page sections.
- `src/lib`: Shared utilities and animation variants.
