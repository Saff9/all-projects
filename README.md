## 🚀 Getting Started

Each project inside this repository is self-contained. Navigate to any project folder to review its individual `README.md`, dependencies, and setup commands.

### Prerequisites
- Node.js (v18+)
- Python (v3.10+)
- Rust / Cargo (for Rust-based tools)
- CMake (for C++ projects)
- Flutter SDK (for mobile apps)
